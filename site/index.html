Cukii Chat

Your coding CLIs, in VS Code

One VS Code chat for the coding CLIs you already pay for — Claude Code, Codex, Kimi Code, Qwen Code, Grok and Cursor agent. Cukii Chat runs the real vendor CLI under your own subscription and shows it as one chat.

Install from Marketplace GitHub issues

Get started in three steps

  1. Install Cukii Install the extension from the VS Code Marketplace. Use a trusted workspace — the extension stays off in Restricted Mode because agents run real commands.
  2. Manage accounts → Install / Log in Pick a vendor you already pay for. Manage accounts → Install downloads that CLI. On macOS and Linux you need curl and tar; Install downloads Node.js for you. On Windows, Install uses npm when it is on PATH, or installs the current Node.js LTS with winget. Then sign in with that vendor.
  3. Choose a model and send Open the chat, pick the model for your signed-in CLI, and send your first message. Tool calls and diffs appear in the same thread.

Remote SSH

In a Remote-SSH window, install the extension and sign in on the remote. The CLI runs on the remote host, alongside your workspace.

Vendor sign-in usually opens a page in your local browser. If it does not, copy the https link from the login terminal. For Codex, you can also copy the link from the Output channel Cukii Chat · codex login.

Reporting bugs

GitHub reports are public. Issues and files linked from them can be read by anyone on the internet.

From the extension, use Commands and model → Report an issue…. Sign in with GitHub through VS Code, review the report text, chat snapshot, screenshots and diagnostic logs, then press Send. Signing in alone does not publish anything — check images and text for private information before you send.

To report a bug you can also open an issue on GitHub. No YouGile account, team invitation or repository write access is needed.

FAQ

Which vendor accounts do I need?
At least one paid (or otherwise entitled) account for a supported coding CLI — for example Claude Code, Codex, Kimi Code, Qwen Code, Grok or Cursor agent. Cukii does not replace those subscriptions; it runs the vendor's CLI locally and surfaces it in one chat UI.
How does Remote SSH change install and sign-in?
Install and CLI sign-in happen in the remote environment where your code lives. Browser-based login still runs on your local machine when possible; if the browser does not open, use the manual https login link from the terminal or Codex output as described above.
What happens to my data when I report on GitHub?
Published issues and attachments are public. The in-chat reporter shows what will be sent before publication. VS Code may request GitHub scopes such as public_repo and read:user; sending a report can pass selected files and an OAuth token over HTTPS to cukii.shop so the intake can verify you and create the issue here — the token is not stored or logged. You can skip that path and file an issue directly on GitHub instead.
