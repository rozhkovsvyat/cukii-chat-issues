# Локальный просмотр лендинга Cukii Chat

Статическая страница в этой папке **не публикуется** автоматически — это черновик установочного лендинга для публичного трекера.

## Быстрый старт

Из корня репозитория:

```bash
cd site
python -m http.server 8080
```

Откройте в браузере: [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

На Windows без Python можно использовать Node.js:

```bash
cd site
npx --yes serve -l 8080
```

## Состав

| Файл | Назначение |
|------|------------|
| `index.html` | Страница установки (английский текст) |
| `styles.css` | Стили без сборки и внешних CDN |
| `assets/icon.png` | Копия `media/icon.png` без изменений |

## Что не трогать

Корневой `README.md`, `.github/` и шаблоны issues остаются как есть — этот каталог `site/` живёт отдельно до отдельного решения о публикации.
